- **ファイル**: 下層ページは管理画面の固定ページ本文ではなく、必ず **`page-XXX.php`**（XXXはスラッグ）というテンプレートファイルを作成して実装してください。
- **画像**: img/draftフォルダに配置した画像を使用、使用する際は画像名を適宜変更し、imgフォルダ直下にコピーして使用してください。
- **h1タグ**: ページ内に必ず **1つだけ** 設置し、内容は管理画面のページタイトルと一致させてください。
- **サイトロゴ**: ヘッダーのロゴはトップページ以外では **`p` タグ** となるようにしてください。
- **パンくずリスト**: テンプレートの仕様から変更せず、**全てのページに設置** してください。
- **実装上の注意**: 他のページ（投稿一覧やお問い合わせ等）に影響が出ないよう、各ページをユニークなIDやクラス名で囲ってください。
- **動的ページ（アーカイブ・詳細）**:
  - カスタム投稿（works / events）やブログカテゴリも、動的な取得は不要で **HTMLによるUI実装のみ** とします。
  - 詳細ページにはアイキャッチ機能を必ず使用してください（OGP用）。
- **ヘッダー・フッター**:既に実装されているものを流用してください。
- **スラッグ**:まだ確定していないので、仮のスラッグで構いません。
- **デザイン**: トップページのデザインを参考に、下層ページ内で同じレイアウトのパーツは全て同じデザインで構いませんし、トップページと同じレイアウトのパーツはトップページのスタイルを流用して構いません。
- **クラス名**:bodyに下層ページのスラッグは追加されるようにして、ページごとのスタイルはそのクラス名を使用して実装、該当ページに関すscssのコードは全てスラッグクラス名内にwrapされるようにしてください
- **レスポンシブ**: ページのレスポンシブデザインを考慮し、モバイルデバイスやタブレットでの表示を確認、レイアウトが崩れていたり謎な改行が入っていないようにしてください。
- **共通見出しの font-size 管理**: `.p-top-sec-head__ja` などトップページと共用するコンポーネントの `font-size` は、下層ページ共通セクション（`design.scss` の下層ページ用メディアクエリ内の `.page-xxx .p-top-sec-head__ja` セレクタリスト）で一元管理してください。個別ページの SCSS ブロック（`.sell { ... }` 等）内では `font-size` を上書きしないでください。`line-height` など font-size 以外のプロパティは、デザイン上必要な場合のみ個別ブロックで指定して構いません。
- **下層ページ共通の font-size 基準**: `p-top-sec-head__ja` は PC: 3.2rem / 768px以下: 2.4rem / 480px以下: 1.8rem を基準とし、全ての下層ページに適用します。新しい下層ページを追加した際は、下層ページ共通セクションのセレクタリストにも忘れず追加してください。
- **img の alt テキスト**: 画像には必ず内容を表す alt テキストを設定してください。装飾目的の画像は `alt=""`、コンテンツ画像はその内容を簡潔に日本語で記述してください。
- **UI共通パーツ参照**: 下層ページの実装に着手する前に `~/Documents/Obsidian Vault/wiki/ui-patterns/INDEX.md` を確認してください。該当するレイアウトパターンがある場合は `lp-lower/{name}/README.md` を読み、`markup.html` と `style.scss` を流用してください。`{slug}` は実際のページslugに一括置換、CSS変数（`--color-main` 等）は案件の `:root {}` 定義済みであることを確認してください。新しいレイアウトを実装した場合、セッション終了時に「このパターンをライブラリに追加しますか？」とユーザーに確認してください。
