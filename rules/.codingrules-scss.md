# design.scss 記述仕様

## ファイル先頭

```scss
@charset "UTF-8";
```

必ず1行目に記載する。

---

## CSS カスタムプロパティ（変数）

色・フォントは `:root` にまとめて定義し、スタイル内では必ず `var(--name)` で参照する。ハードコードは禁止。

```scss
:root {
  --color-text: #17130f;
  --color-bg: #fff;
  --color-primary: #9d9486;
  --font-en: "Lora", serif;
}

/* 使用例 */
.foo {
  color: var(--color-text);
  background-color: var(--color-bg);
}
```

---

## `&`（アンパサンド）全面禁止

`&` はいかなる用途でも使用しない。疑似クラス・疑似要素・状態クラス・クラス名の連結、すべて禁止。

```scss
/* NG */
.mainNavi {
  &.menu-open { ... }
  &::before { ... }
  &:hover { ... }
  &__cta { ... }
}

/* OK */
.mainNavi.menu-open { ... }
#menuNavi__menu::before { ... }
.header-pcNavi li:hover > ul { ... }
.header-pcNavi__cta { ... }
```

## ネスト：何をネストするか

### ページ固有スタイルの基本形

下層ページなどページ固有のスタイルは、ページIDまたは最上位ページクラスで必ず1つの親ブロックにまとめる。  
同じページ内でしか使わない子クラスは、セレクタをフラットに展開せず、ページ親ブロックの内側にネストする。

```scss
/* OK：ページ固有スタイルはページIDの中にまとめる */
#page-about {
  .about-service-grid {
    display: grid;
    grid-template-columns: repeat(3, minmax(0, 1fr));
    gap: clamp(16px, 2vw, 28px);
  }

  .about-service-card {
    display: flex;
    flex-direction: column;
  }

  .about-service-card__img {
    overflow: hidden;
  }
}
```

```scss
/* NG：同じページIDを各セレクタに繰り返してフラット展開しない */
#page-about .about-service-grid { ... }
#page-about .about-service-card { ... }
#page-about .about-service-card__img { ... }
```

### ネストするもの ✅

**親要素の「子孫」にあたるセレクタ**をネストする。  
タグセレクタ（`ul`、`li`、`a`、`p`、`img` 等）および、親の文脈でしか使われないクラスセレクタ。

```scss
/* 親ブロック内にタグセレクタをネスト */
.header-pcNavi {
  ul {
    display: flex;
    gap: 40px;
  }

  li {
    position: relative;

    > ul {
      display: none;

      a {
        font-size: 1.3rem;
      }
    }
  }

  a,
  p {
    color: var(--color-text);
  }
}
```

```scss
/* ページ固有ブロック内に子コンポーネントをネスト */
.top-page {
  .top-kv {
    padding: 86px 0 0;

    .top-kv__lead {
      padding: 0 34px 37px;
    }

    .top-kv__title {
      font-size: clamp(3.5rem, 3.8vw, 5.1rem);
    }
  }
}
```

### ネストしないもの ❌

以下は、同じセレクタ自身の内側にはネストせず、フラットに書く。  
ただしページ固有スタイルでは、`#page-about { .about-service-card__img { ... } }` のようにページ親ブロックの内側へ置いてよい。

| パターン | 理由 |
|---|---|
| 同一要素の疑似要素 `.foo::before` | `&` なしではネスト不可 |
| 同一要素の状態クラス `.foo.is-open` | `&` なしではネスト不可 |
| BEM element `.foo__bar` | `&` なしではネスト不可 |
| コンテキストセレクタ `body.xxx .foo` | `&` なしではネスト不可 |

```scss
/* NG：同一要素の疑似要素を & なしでネストするとセレクタが壊れる */
#menuNavi__menu {
  #menuNavi__menu::before { ... }  /* → #menuNavi__menu #menuNavi__menu::before になる */
}

/* OK：フラットに書く */
#menuNavi__menu { ... }
#menuNavi__menu::before { ... }
#menuNavi__menu::after { ... }
#menuNavi__menu.icon-close { ... }
#menuNavi__menu.icon-close::before { ... }
#menuNavi__menu.icon-close::after { ... }
```

```scss
/* NG */
.mainNavi {
  .mainNavi.menu-open { ... }  /* → .mainNavi .mainNavi.menu-open になる */
}

/* OK */
.mainNavi { ... }
.mainNavi.menu-open { ... }
```

```scss
/* BEM element はフラット */
.header-pcNavi { ... }
.header-pcNavi__cta { ... }
.header-pcNavi__cta + .header-pcNavi__cta { ... }
.header-pcNavi__cta a { ... }
.header-pcNavi__cta a:hover,
.header-pcNavi__cta a:focus { ... }
```

### ネスト深さの判断基準

- 状態・装飾（`::before`、`:hover`、`.is-open`）→ **フラット**
- DOM上の子孫要素（`ul > li > a` など）→ **ネスト**
- BEM element（`__`付きクラス）→ **`&__` では書かない**。ページ固有の場合はページ親ブロック内に単独クラスとして置く
- BEM内の子孫タグ（`.foo__bar a`）→ **フラット**（`.foo__bar` の外か、`.foo__bar` ブロック内にネスト）

## @media クエリ

セレクタブロックの**内側**に書く。ルートレベルには書かない。

```scss
/* OK */
.l-header {
  padding: 0 56px;

  @media screen and (max-width: 1000px) {
    padding: 0 14px;
  }
}

/* NG */
.l-header {
  padding: 0 56px;
}
@media screen and (max-width: 1000px) {
  .l-header {
    padding: 0 14px;
  }
}
```

複数セレクタをまとめてレスポンシブ上書きしたい場合は、親ブロックの `@media` 内にまとめて子セレクタを書く。

```scss
.mainNavi {
  @media screen and (max-width: 1200px) {
    ul {
      gap: 16px;
    }
    a,
    p {
      font-size: 1.3rem;
    }
  }
}
```

---

## ブレークポイント

| 用途 | 記述 |
|---|---|
| PC 幅狭（1001px〜1500px） | `@media screen and (min-width: 1001px) and (max-width: 1500px)` |
| タブレット以下（〜1000px） | `@media screen and (max-width: 1000px)` |
| スマホ以上（641px〜） | `@media screen and (min-width: 641px)` |
| スマホ（〜640px） | `@media screen and (max-width: 640px)` |
| 小スマホ（〜560px） | `@media screen and (max-width: 560px)` |

---

## フォントサイズ・長さの単位

- フォントサイズは `rem` を使用する。`px` は禁止。
- レスポンシブなサイズには `clamp(min, 推奨, max)` を使用する。
- `vw` 単位は `clamp()` の推奨値として使用する。

```scss
font-size: clamp(1.4rem, 0.84vw, 1.7rem);
padding: 0 clamp(32px, 2.75vw, 56px);
gap: clamp(24px, 2vw, 40px);
```

---

## セレクタの並び順（同一ブロック内）

1. ベーススタイル（`display`、`position`、`width`、`color` 等）
2. `@media` クエリ（大きい順 or 設計上の順）
3. 子・孫セレクタのネスト（タグ順）

---

## その他

- **コメント**: `/* セクション名 */` 形式。`//` は使用しない（CSS互換のため）。
- **ページ固有スタイル**: `.top-page { }` のように最上位クラスで囲い、他ページへの影響を防ぐ。
- **共通パーツ**: ヘッダー・ナビ等は `.l-header`、`.mainNavi` のようなレイアウトクラスで定義し、`.top-page` の外に置く。
