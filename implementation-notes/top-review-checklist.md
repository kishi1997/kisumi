# トップページ レビュー観点

## 毎回の確認項目

- `home.php` / `design.scss` / `design.css` / `design.js` 以外に不要な変更が出ていないか
- 画像は `img/draft` を直接参照していないか
- 使用画像が `img` 直下へコピーされ、トップ専用なら `top-` 命名になっているか
- トップ専用CSSが他テンプレートへ漏れにくい構造か
- `design.scss` と `design.css` が同期しているか

## レイアウト確認

- PCでカンプの余白感、文字サイズ感、画像比率感が大きくズレていないか
- SPで情報の順序がカンプと合っているか
- `1000px` 以下でレスポンシブが成立しているか
- `768px` / `390px` でも横スクロールが出ないか
- テキストの重なり、切れ、ボタンの潰れがないか
- 固定要素が本文を過度に隠していないか

## セクション別の重点

### ヘッダー

- PCでロゴ、ナビ、右側ボタンの密度感が合っているか
- SPでハンバーガー表示がカンプに近いか
- `top-pc-menu.png` / `top-sp-menu.png` のレイアウトに近づいているか

### KV

- メイン画像が正しい写真か
- 大見出しが画像上端にかかる構成になっているか
- 右上リード文、左縦英字、固定導線の位置関係が近いか

### Intro

- 背景の薄い図面演出が出ているか
- PC縦書きの密度が近いか
- SPでも崩れず、読み方向が極端に不自然でないか

### Gallery

- Slickが正しく動いているか
- 矢印表示、枚数、余白がカンプに近いか
- SPで1枚見え前提でも破綻していないか

### FAQ

- ボックス角丸、余白、罫線が近いか
- Q/Aの可読性が落ちていないか

### Footer

- `footer.php` にCVとフッターをまとめて記述しているか
- SPで4導線が縦積みになっているか

## 総合レビュー時の追加項目

- 全セクション通しで背景色の切り替えが自然か
- ボタン、ラベル、小見出しのデザインルールが統一されているか
- セクション間の上下余白がバラついていないか
- 画像の明るさやトリミングがカンプと大きくズレていないか
